Installez votre Vocalink

Dites une idée à voix haute : elle devient un projet, un email à écrire, un appel à passer ou une simple note. Ce guide vous accompagne pas à pas, sans connaissances techniques.

Avant de commencer

⏱️ 30 à 45 minune seule fois
💻 Un ordinateurplus confortable qu'un téléphone pour installer
📱 Votre téléphonepour les codes de vérification
💳 Une carte bancairepour le crédit OpenAI

Combien ça coûte ? L'hébergement est gratuit. Seule l'intelligence artificielle (OpenAI) est payante, à l'usage : quelques centimes par idée, soit quelques euros par mois. Vous achetez un crédit à l'avance : pas d'abonnement, pas de mauvaise surprise.

Vous allez créer 3 comptes, tous à votre nom :

  • 1GitHub — garde une copie du programme. Gratuit. Vous n'aurez plus à y retourner ensuite.
  • 2OpenAI — l'intelligence artificielle qui comprend votre voix. Payant à l'usage.
  • 3Vercel — fait tourner l'application sur Internet. Gratuit. Se crée en un clic grâce à GitHub.
Astuce : ouvrez une note (Bloc-notes, Notes…) pour y coller votre clé OpenAI (étape 2) et votre mot de passe (étape 3). Vous en aurez besoin à l'étape 4.
0 / 6 étapes
1

Créer votre compte GitHub

environ 5 minutes
  1. Ouvrez github.com/signup.
  2. Saisissez votre adresse email, puis cliquez sur Continue.
  3. Choisissez un mot de passe, puis un nom d'utilisateur (par exemple marie-dupont), puis Continue.
  4. Faites la petite vérification « je ne suis pas un robot ».
  5. Ouvrez votre boîte mail : GitHub vous envoie un code. Recopiez-le.
  6. Si GitHub vous pose des questions, choisissez les réponses les plus simples ou cliquez sur Skip. Si on vous propose une offre, choisissez Free (gratuit).
2

Obtenir votre clé OpenAI

environ 10 minutes

La « clé » est un code secret qui autorise votre Vocalink à utiliser OpenAI, à vos frais. Ne la partagez avec personne.

a. Créer le compte

  1. Ouvrez platform.openai.com/signup.
  2. Créez un compte (email et mot de passe, ou Continue with Google).
  3. Confirmez votre email et, si on vous le demande, votre numéro de téléphone.
Attention : un abonnement ChatGPT ne suffit pas et n'est pas nécessaire. Il s'agit ici de la « plateforme » d'OpenAI, qui est un service séparé.

b. Ajouter du crédit

  1. Ouvrez la page de facturation.
  2. Cliquez sur Add payment details, choisissez Individual (particulier) et saisissez votre carte.
  3. Achetez 5 $ de crédit : c'est le minimum, et largement suffisant pour commencer.
  4. Laissez la recharge automatique (auto recharge) désactivée : vous ne dépenserez jamais plus que ce crédit.

c. Créer la clé

  1. Ouvrez la page des clés.
  2. Cliquez sur Create new secret key.
  3. Nom : Vocalink. Ne changez rien d'autre. Cliquez sur Create secret key.
  4. Une longue suite de caractères commençant par sk- apparaît. Cliquez sur Copy et collez-la tout de suite dans votre note.
OpenAI n'affichera plus jamais cette clé. Si vous la perdez, pas de panique : supprimez-la et créez-en une nouvelle de la même façon.
3

Choisir le mot de passe de votre Vocalink

1 minute

Votre Vocalink sera sur Internet : ce mot de passe empêche toute autre personne d'y entrer.

  1. Choisissez un mot de passe nouveau, d'au moins 12 caractères. Trois mots au hasard, c'est facile à retenir : girafe-orage-violon42.
  2. Notez-le dans votre note.
4

Installer Vocalink

environ 10 minutes, dont 3 d'attente

Ce bouton ouvre Vercel, qui va installer votre Vocalink. Gardez votre note à portée de main.

▲ Installer Vocalink

S'ouvre dans un nouvel onglet — revenez ici pour suivre les étapes.

  1. Compte Vercel : cliquez sur Continue with GitHub, puis Authorize Vercel. Si on vous demande votre type d'usage, choisissez Hobby (personnel, gratuit) et indiquez votre nom.
  2. Copie du programme : Vercel propose de créer une copie nommée mon-vocalink. Laissez Private repository coché et cliquez sur Create. Si GitHub vous demande une autorisation, acceptez (Install ou Authorize).
  3. Base de données : Vercel propose Neon, l'endroit où vos idées seront rangées. Cliquez sur Add ou Create, puis :
    • choisissez l'offre Free (gratuite) ;
    • si on vous demande une région, choisissez l'Europe, par exemple Frankfurt ;
    • acceptez et validez.
  4. Vos deux secrets : remplissez les deux cases, sans espace avant ni après.
    • OPENAI_API_KEY → votre clé OpenAI (elle commence par sk-) ;
    • APP_PASSWORD → votre mot de passe de l'étape 3.
  5. Cliquez sur Deploy. Patientez 2 à 4 minutes sans fermer la page.
  6. Des confettis 🎉 : c'est installé ! Cliquez sur Continue to Dashboard.
Votre adresse Vocalink s'affiche sous la miniature de l'application, sous la forme mon-vocalink-xxxx.vercel.app. Notez-la : c'est votre Vocalink.
5

Premier essai

2 minutes
  1. Ouvrez votre adresse Vocalink et saisissez votre mot de passe.
  2. Cliquez sur Enregistrer une idée, puis Démarrer l'enregistrement, et autorisez le micro.
  3. Dites par exemple :
    « Rappeler Jean Dupont, directeur chez ACME, au 06 12 34 56 78, jeudi à 10 heures. »
  4. Cliquez sur Arrêter. Quelques secondes plus tard, Vocalink affiche le texte, la catégorie Appel / Rappel, le contact et la date.
  5. Corrigez si besoin, puis cliquez sur Enregistrer.
6

Mettre Vocalink sur votre téléphone

1 minute

Vocalink s'utilise comme une application, sans passer par un store.

iPhone

  1. Ouvrez votre adresse dans Safari et connectez-vous.
  2. Touchez Partager (le carré avec une flèche).
  3. Choisissez Sur l'écran d'accueil, puis Ajouter.

Android

  1. Ouvrez votre adresse dans Chrome et connectez-vous.
  2. Touchez le menu ⋮ en haut à droite.
  3. Choisissez Installer l'application (ou Ajouter à l'écran d'accueil).

L'icône Vocalink apparaît avec vos autres applications. À la première dictée, autorisez le micro. Si le micro ne réagit pas depuis l'icône, ouvrez simplement votre adresse dans le navigateur.

🎉 Bravo, votre Vocalink est prêt !

Dictez, relisez, enregistrez. Retrouvez tout dans Voir mes idées, avec la recherche par nom, société ou mot-clé.

Besoin d'aide ?

« Transcription indisponible » ou « La transcription a échoué »

La clé OpenAI est absente ou mal copiée, ou votre crédit est épuisé. Vérifiez votre crédit sur la page de facturation OpenAI. Si besoin, créez une nouvelle clé et remplacez-la (voir ci-dessous).

Changer la clé OpenAI ou le mot de passe (ou mot de passe oublié)
  1. Sur vercel.com, ouvrez votre projet mon-vocalink → Settings → Environment Variables.
  2. Sur la ligne OPENAI_API_KEY ou APP_PASSWORD : ⋯ → Edit, collez la nouvelle valeur, Save.
  3. Onglet Deployments, première ligne : ⋯ → Redeploy. Attendez 2 minutes.
L'installation (étape 4) s'est arrêtée sur une erreur rouge

Dans Vercel, onglet Deployments → ⋯ → Redeploy. Un deuxième essai suffit souvent.

Si la base Neon n'a pas été créée : dans votre projet, onglet Storage → Create Database → Neon → Free → Connect, puis Redeploy.

Le micro ne fonctionne pas

Vérifiez que le navigateur a le droit d'utiliser le micro (Réglages du téléphone → Safari ou Chrome → Micro). L'adresse doit bien commencer par https://.

Bon à savoir : données, usage, mises à jour
  • Vos données sont rangées dans votre base, protégée par votre mot de passe. Le son est envoyé à OpenAI pour être transcrit, puis n'est conservé nulle part par Vocalink.
  • Contacts : si vous notez les coordonnées d'autres personnes, gardez-les pour votre usage personnel.
  • Usage : l'offre gratuite de Vercel est prévue pour un usage personnel, non commercial.
  • Mises à jour : votre Vocalink est une copie indépendante. Il ne change pas tout seul et continue de fonctionner tel quel.
  • Options avancées (Notion, Google Tasks, email récapitulatif) : voir le guide technique.
Les sites cités changent parfois le nom exact de leurs boutons : si un bouton ne correspond pas tout à fait, choisissez celui qui s'en approche le plus.
