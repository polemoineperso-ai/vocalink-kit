Un souci après l'installation ?

La dictée ne marche plus (« Crédit épuisé », « Clé refusée »…)
Dans Vocalink, ouvrez Réglages → Tout fonctionne ? : il dit ce qui coince.
  • Crédit OpenAI épuisé ou expiré (le crédit expire un an après l'achat) : rachetez du crédit sur votre compte OpenAI. Rien d'autre à faire.
  • Clé OpenAI refusée : elle a expiré ou a été supprimée. Créez-en une nouvelle et remplacez-la (voir juste en dessous).
Changer la clé ou le mot de passe (ou mot de passe oublié)
  1. Sur vercel.com, ouvrez votre projet mon-vocalink.
  2. Settings → Environment Variables.
  3. Sur la ligne à changer : ⋯ → Edit, collez la nouvelle valeur, Save.
  4. Onglet Deployments, première ligne : ⋯ → Redeploy. Attendez 2 minutes.
Le micro ne marche pas
Dans les réglages du téléphone, autorisez le micro pour Safari (ou Chrome). Si ça ne marche pas depuis l'icône, ouvrez votre adresse Vocalink directement dans le navigateur.
Mettre à jour mon Vocalink

Quand une nouvelle version existe, une pastille apparaît sur votre initiale dans Vocalink, et Réglages l'annonce. La mise à jour prend 2 minutes et ne touche pas à vos idées.

  1. Sur github.com, ouvrez votre dépôt mon-vocalink.
  2. Onglet Actions, puis à gauche Mettre à jour Vocalink.
  3. À droite : Run workflow, puis le bouton vert Run workflow.
  4. Attendez la coche verte (environ 1 minute), puis 2 à 3 minutes que Vercel remette votre assistant en ligne. Fermez et rouvrez l'app.

Vos idées n'appartiennent qu'à vous : les bons réflexes

Votre Vocalink n'est pas l'appli d'une entreprise : c'est le vôtre, installé sur vos propres comptes. C'est ce qui le rend privé, et c'est pour ça que ces quelques réflexes comptent.

Vous êtes la seule personne à y avoir accès

Vos idées sont rangées dans votre base de données, sur vos comptes. Personne d'autre ne peut les lire, pas même la personne qui vous a envoyé ce guide. Le revers : personne ne pourra non plus les récupérer à votre place. Gardez précieusement votre note (clé et mot de passe) et vos accès GitHub, Vercel et OpenAI.

Votre mot de passe ouvre tout

Quiconque le connaît voit toutes vos idées. Ne le donnez à personne et ne le réutilisez pas ailleurs. Téléphone perdu, ou mot de passe qui a circulé ? Changez-le dans Vercel (marche à suivre dans « Un souci après l'installation ? ») : tous les appareils connectés sont aussitôt déconnectés. Sur un appareil partagé, déconnectez-vous depuis Réglages.

Votre clé OpenAI, c'est comme une carte bancaire

Elle permet de dépenser votre crédit. Ne l'envoyez jamais par email, message ou capture d'écran, à personne, même pour vous faire aider. Si elle a pu fuiter : supprimez-la sur la page des clés OpenAI et créez-en une nouvelle. Laissez la recharge automatique désactivée : au pire, vous perdez le crédit restant, jamais plus.

Ce qui sort de chez vous

Pour vous comprendre, l'enregistrement de votre voix et le texte de vos idées passent par OpenAI. Vocalink ne garde pas l'enregistrement. Selon ses conditions, OpenAI n'entraîne pas ses modèles avec ce qui passe par une clé comme la vôtre. Si vous activez les options avancées (Notion, Google Tasks, email), vos idées y sont aussi copiées. Enfin, une fois par jour, l'app regarde sur le site du guide s'il existe une nouvelle version, sans rien envoyer de vos données.

Pas de secrets dans vos idées

Vocalink est fait pour des idées, pas pour servir de coffre-fort : ne dictez ni codes, ni mots de passe, ni numéros de carte, ni informations de santé très personnelles. Les coordonnées de vos contacts sont pour votre usage personnel : ne les diffusez pas, par respect pour eux.

Les notifications se lisent sur l'écran verrouillé

Le brief du matin affiche le titre de vos idées. Si d'autres voient votre téléphone, masquez les aperçus : sur iPhone, Réglages → Notifications → Afficher les aperçus → Si déverrouillé. Sur Android, masquez le contenu sensible sur l'écran de verrouillage.

Supprimer, c'est définitif

Une idée supprimée ne revient pas : en cas de doute, préférez Archiver. Et ne supprimez jamais le projet mon-vocalink sur Vercel ni sa base de données : toutes vos idées partiraient avec.

Et le RGPD ?

Usage personnel (vos idées, vos proches) : le RGPD ne s'applique pas, c'est l'exception de l'usage « personnel ou domestique ».

Usage professionnel (clients, prospects, collègues) : il s'applique, et c'est vous qui êtes responsable des données. Notez seulement le nécessaire, supprimez ce qui ne sert plus, effacez un contact s'il vous le demande, évitez les données sensibles (santé, opinions…) et vérifiez que votre employeur autorise ce type d'outil.

Où sont vos données : la base et les serveurs de votre Vocalink sont en Europe (Francfort) ; seule la compréhension de la voix et du texte passe par OpenAI, aux États-Unis (ainsi que Notion, Google ou l'email si vous activez les options avancées).
